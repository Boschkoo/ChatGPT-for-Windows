# ChatGPT for Windows

Desktop application for ChatGPT — built with Electron before OpenAI released their official desktop app. One of the first standalone ChatGPT clients for Windows.

## Features

- Native Windows desktop app
- Direct ChatGPT access without browser
- Minimal, clean interface
- Auto-updates

## Tech Stack

- Electron
- HTML/CSS/JavaScript
- OpenAI ChatGPT (Web)

## Note

This project was created when there was no official ChatGPT desktop app available. It served as a quick-access client that ran natively on Windows.
